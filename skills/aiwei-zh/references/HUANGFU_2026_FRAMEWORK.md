# 皇甫博媛 2026 六维 AI 味框架

## 出处

皇甫博媛.《"AI 味"与"人机感"：社交媒体话语中的机器主体性建构》[J]. 新闻与写作, 2026(3): 89-98.

作者通过 python 爬虫抓取微博话题"人机感""AI 味""活人感""人味"下的 1283 条原创帖子，清洗后保留 1084 条作为分析语料。采用无监督机器学习算法（LDA 主题模型 + 文本聚类，结合困惑度与主题连贯性指标确定最优主题数与主题-关键词分布），最终提炼 6 个主范畴。

## 核心论点（影响本 skill 设计）

1. **"AI 味" / "人机感" 不是一种 AI 的客观属性，而是用户在社交媒体话语实践中持续协商出来的边界判断**。
2. 用户标注为机器气质的关键词集中在六个维度上，每个维度都有明确的"人侧 vs 机侧"对立词表。
3. **用户偏爱带有瑕疵的活人感**："好喜欢那种带有瑕疵的活人感"；"这些不完美，才是艺术的心跳"。
4. 工具理性的"高效""完整""程式化"在工程场景是正面词，在情感 / 创作 / 学术写作场景却是 AI 味的强标记。语境敏感是判断的关键。

## 段首重复（burstiness）

连续 3 段以相同的前 4 个中文字符开头时触发。这是 AI 写作的典型节奏指纹：

- "本节首先..." / "本节首先..." / "本节首先..."
- "为了进一步..." / "为了进一步..." / "为了进一步..."
- "其一..." / "其二..." / "其三..."（这条要谨慎，"其一/其二/其三" 是合法的中文枚举结构，不一律算）

修复方法：把至少一段重写为不同的句法形态（前置状语、对比连接、问题句、独立段落）。

## 段首清嗓子（throat clearing）

段落首条非空可见行匹配以下模式即触发：

- 综上所述 / 总而言之 / 总的来说 / 由此可见
- 值得指出的是 / 值得注意的是 / 需要指出的是 / 需要说明的是
- 不难发现 / 不难看出 / 众所周知 / 毋庸讳言
- "首先,""其次,""然而,""此外," 开头
- 一方面 / 另一方面

每个触发记一次 `[Script] MINOR`。

## 标点模式（破折号 hard gate）

详见 `EMDASH_PLAYBOOK.md`。简言之：

- `——` (U+2014 双连，中文破折号常见编码)：CRITICAL，必须为 0
- `—` (U+2014 单字符)：CRITICAL，必须为 0
- `–` (U+2013 en dash)：在页码范围 `[1-2]`、年代范围 `2025–2026`、英文复合修饰语 `author–editor–reader` 中合法保留，其它情况标 MAJOR

## 完美对称结构

论文指出"AI 通过完美对称、机械排比制造'结构化'印象"。本 skill 检测：

1. 同一段内出现 3 个及以上"X：Y" 冒号结构（每个冒号后是平行的解释）
2. 同一段内出现 3 个及以上"X，即 Y" 结构
3. 同一段内出现 3 个及以上"X——Y" 破折号结构（已被 hard gate 覆盖，重复触发只记一次）
4. 三联排比 + 完全相同的句法（"X 的 A、X 的 B、X 的 C"）

这些不是禁止，是"风险信号"。建议至少打散一个，让节奏不齐。

## 论文里的关键引述（用户原话，用作判定依据）

- "刚刚通过图灵测试，终于进入到人类社会，努力学习旁边人的一举一动，反而学得四不像，太冷了"
- "这机器人真的很死板，永远好像程序设定一样的模板式回复，简直人机……转人工"
- "AI 学会了'怎么写容易让人哭出来'，于是一个劲戳我泪点，但完全是 AI 味没有活人味"
- "看到微博下面那种弱智人机评论就头疼，还非要装成真人发言，蹩脚的伪人感让人作呕"
- "好喜欢那种带有瑕疵的活人感"
- "这些不完美，才是艺术的心跳"

这些不是结论，是用户在用日常话语反向定义"什么不是 AI 写的"。

## 应用边界

本框架来自**社交媒体话语**研究，迁移到**学术写作**时需要注意：

1. 学术写作允许更高的逻辑、结构、完整密度（不能要求论文"松弛""少年感"）。
2. 学术写作的"瑕疵"指**节奏不一律**、**句长有变化**、**偶尔保留口语化**，不是"故意写错"。
3. 学术写作中"结构化""逻辑"等词高频是合法的，本 skill 通过提高阈值反映这一点。
4. 破折号在学术中文里历来稀疏（远低于 LLM 输出），所以 hard gate = 0 是合理的。
