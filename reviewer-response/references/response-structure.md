# Response Structure

Default package order:

1. response strategy summary
2. comment-response tracker
3. point-by-point response package
4. revision-evidence checklist
5. missing information and risk flags

Preferred response pattern per comment:

1. acknowledge the concern
2. state the action taken or the scientific rationale for partial disagreement
3. point to the draft evidence, attachment, or explicit placeholder

Keep replies concise, traceable, and professional.

This structure should work for:

- journal revision letters
- conference rebuttals
- transfer-after-review packages
- grant-panel response memos
