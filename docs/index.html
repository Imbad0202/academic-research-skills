Academic Research Skills — Hermes Adaptation

Hermes Agent skills for academic research, manuscript writing, peer review simulation, and research-to-publication pipelines.

GitHub repository · Upstream ARS

Install

git clone -b hermes-adaptation https://github.com/maximosovsky/academic-research-skills.git
cd academic-research-skills
bash hermes/scripts/install-local.sh all

Then start a fresh Hermes session or run /reload-skills.

Skills

hermes-academic-deep-research

Research questions, literature review, systematic-review planning, fact-checking.

hermes-academic-paper

Planning, outlining, drafting, revising, formatting and declarations.

hermes-academic-reviewer

Editor + reviewers + devil's advocate + editorial decision + revision roadmap.

hermes-academic-pipeline

End-to-end workflow: research → write → integrity → review → revise → finalize.

Usage

/skill hermes-academic-reviewer
Полная peer-review имитация Editor + 3 reviewers + devil's advocate + editorial decision для этого PDF.
