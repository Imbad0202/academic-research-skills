# Revision Protocol

## Inputs

- Manuscript or section.
- Reviewer comments or internal critique.
- Target venue and genre.

## Steps

1. Parse comments into discrete issues.
2. Classify each issue: conceptual, methodological, evidence, structure, style, formatting.
3. Prioritize: major / moderate / minor.
4. Decide response: accept, partially accept, rebut with evidence, defer to limitations.
5. Revise only the affected sections unless a structural rewrite is required.
6. Produce a change log and response-to-reviewers table when needed.

## Rule

Do not accept all reviewer suggestions uncritically. Protect the paper's core contribution while fixing valid weaknesses.
