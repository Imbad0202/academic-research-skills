# Formatting and Submission Checklist

## Before Formatting

- Target journal selected.
- Article type confirmed.
- Word count within limit.
- Abstract type correct.
- Figures/tables numbered and cited.
- References formatted and checked.
- Declarations complete.

## Package

- Manuscript file.
- Title page if required.
- Blinded version if required.
- Figures as separate files if required.
- Supplementary materials.
- Cover letter.
- Author contributions and declarations.

## APC / Fees

Check whether the venue has:
- submission fee;
- article processing charge;
- mandatory open access;
- waiver policy.

Do not recommend a mandatory-fee venue if the user has not approved APC exposure.
