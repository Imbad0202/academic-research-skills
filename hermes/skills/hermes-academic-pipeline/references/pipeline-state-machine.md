# Pipeline State Machine

## Stages

1. Research.
2. Plan/write.
3. Integrity check.
4. Peer review.
5. Revision.
6. Final integrity.
7. Finalize.

## Transitions

- Research -> Plan only after research question and scope are stable.
- Plan -> Draft only after outline approval or explicit autonomous permission.
- Draft -> Review only after basic integrity check.
- Review -> Revision only after editorial decision is synthesized.
- Revision -> Finalize only after final claim/support check.

## Entry Points

A user may enter at any stage if they provide appropriate materials.

## Rule

Never silently skip an integrity or user-decision boundary when the next step changes the manuscript's argument, evidence, or submission target.
