# Completed Preprint Pipeline

Use when the user provides a full PDF/DOCX/MD manuscript.

1. Extract text and metadata.
2. Identify title, genre, authors, abstract, sections, references, declarations.
3. Run quick editorial diagnosis.
4. Run full peer-review simulation if requested.
5. Run claim/citation audit for major claims.
6. Produce revision roadmap.
7. Check journal fit and APC exposure.
8. Prepare final formatting and declarations.

## Recommended Output

- Editorial decision.
- Reviewer reports.
- Devil's Advocate risks.
- Major/moderate/minor roadmap.
- Submission-readiness checklist.
