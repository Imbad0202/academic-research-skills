# Checkpoint Protocol

Use concise checkpoints after major stages.

## Format

```text
Stage complete: <stage>
Produced: <artifacts>
Main risks: <risks or none>
Recommended next step: <stage>
Decision needed: <what user should approve/change>
```

## When to Ask

Ask when the next step changes scope, venue, argument, publication target, or manuscript content.

## When Not to Ask

If the user explicitly requested autonomous execution through all stages, proceed and report checkpoints in the final summary.
