# Integrity Gates

## Gate 1: Pre-review

Check before simulated peer review:

- manuscript genre;
- citation existence for key references;
- claim support for central claims;
- overclaims;
- source reliability;
- ethics/data/funding/AI declarations;
- missing limitations.

## Gate 2: Final

Check before submission:

- reviewer issues addressed;
- new claims introduced during revision are supported;
- references formatted and complete;
- target journal requirements met;
- declarations match venue policy.

## Rule

For conceptual papers, integrity means honest evidentiary status, not empirical proof.
