# Systematic Review Planning Protocol

Use when the user asks for systematic review, PRISMA, meta-analysis, scoping review, or evidence synthesis.

## Protocol Elements

- Review type: systematic / scoping / rapid / narrative / meta-analysis.
- Research question: PICO, SPIDER, FINER, or domain-specific equivalent.
- Databases and search surfaces.
- Search strings per database.
- Inclusion/exclusion criteria.
- Screening workflow: title/abstract -> full text -> final corpus.
- Extraction fields.
- Bias/quality appraisal plan.
- Synthesis plan: narrative, thematic, quantitative, meta-analysis.

## Pitfall

Do not promise a systematic review if only an informal search was performed. Call it a narrative or rapid review unless the protocol is actually followed.
