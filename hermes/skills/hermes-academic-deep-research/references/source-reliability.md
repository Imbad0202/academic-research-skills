# Source Reliability Scale

A — Peer-reviewed article, academic book, official dataset, archival source.

B — Published professional/educational source, official guidance, indexed preprint with transparent methods.

C — Detailed grey literature, credible organization, public technical report.

D — Forum/blog/social-media testimony, useful for netnography but weak as proof.

E — Single visual lead, snippet, unverifiable or unstable page.

Use D/E for hypothesis generation unless independently corroborated.
