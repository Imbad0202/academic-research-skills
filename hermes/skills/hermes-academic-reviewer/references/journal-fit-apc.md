# Journal Fit and APC Risk

## Fit Dimensions

- Scope match.
- Article type accepted.
- Method type accepted.
- Audience match.
- Regional/language fit.
- Word count and structure limits.
- Figure/table limits.
- Ethics and data policies.
- APC, submission fees, mandatory open access.

|---|---|---|---|---|---|

## Rule

If fees are mandatory, state them clearly and do not recommend submission without user approval.
