# Eval preregistration: panel claim factuality (#1002)

Frozen with `plan.json`, `rubric.md`, `prompts/`, `scripts/extract_panel_claims.py`,
and `scripts/dispatch_panel_claim_audit.py` in one commit, before any judge call
on a claim. A change to any of them after that call is a new plan
version, logged as an amendment; the frozen files are never edited in place.

## Bars

- contrast_detection: per judge, at least 0.95 of the false contrast sentences are judged `false` by both replicates. A miss, or a missing verdict on any contrast sentence, voids that judge's claim verdicts.
- contrast_false_flag: per judge, at most 0.05 of the accurate contrast sentences are judged `false` by either replicate. A miss voids that judge's claim verdicts.
- With one valid judge the run is exploratory (per-judge counts only, no decision); with none it is void.
- false_claim_rate: adjudicated false claims divided by all 805 claims, overall and by seat. At least 0.03, with both judges past the contrast gate, means plan the second part of #1002 (a check between the panel and the synthesizer).
- panels_with_false_claim: the share of the 17 panels with at least one adjudicated false claim. At least 0.30, with both judges past the contrast gate, also means plan the second part. Below both decision bars, the second part is not planned on this evidence.

## Arms

Each arm is a judge, a generator, or a verifier, not a treatment. The codex and agy calls run through a subscription CLI, so they carry no per-call charge; their settled cost is `unknown` and the binding limits are the subscription usage limits and time. From version 4 the Google judge runs on the paid Gemini API, and its cost is settled from the `usageMetadata` of each response.

- judge `gpt-6-astra` (OpenAI family): `codex exec --json`, model_reasoning_effort=xhigh, `skills.include_instructions=false`, read-only, empty working directory, prompt on stdin. The read-only sandbox still lets the model read files, so a reply whose event stream shows any item other than a message or reasoning (a command, a file read, a tool) is a transport failure and stops the run. Price-table estimate at 10/50 USD per MTok: about 0.14 USD per item at 4,000 in and 2,000 out tokens; a batch is about 7,000 in tokens.
- judge `gemini-4-argon-high` (Google family): the Gemini API `generateContent` method, model `gemini-4-argon`, `thinkingLevel` high, `maxOutputTokens` 32,768 (the model's limit, which counts thinking tokens), no tools, no system instruction, and one user message that holds the batch prompt. `scripts/dispatch_panel_claim_audit.py gemini-api-call` sends it from an empty working directory, with the key read from `GEMINI_API_KEY` and sent only in the request header. An error body, a model version other than `gemini-4-argon`, a finish reason other than `STOP`, or a reply part other than text (a function call, code) is a transport failure and stops the run. Price: 2 USD per MTok in and 10 USD per MTok out, thinking included (Google's pricing page, rates through 2026-11-30); a batch is about 7,000 in tokens, and the pilot measures the output. In v1 and v2 this judge was `gemini-3.8-flash-high` and in v3 "Gemini 4 Argon (High)", both through `agy -p` (Amendments).
- generator `claude-opus-5-5-high` (Anthropic family): `agy -p`, model "Claude Opus 5.5 (High)", the same flags and step rule, 20 contrast pairs per manuscript, 3 calls.
- verifier `gpt-6-astra`: the codex settings above, one call per manuscript over its mechanically valid pairs.
- Context the agy transport adds. From version 4 only the generator runs through agy, and its pairs were generated before version 4. A probe on 2026-10-23 (a fresh call asked to list every instruction, rule, memory, skill, or project file it received) found, for both agy models, a shared-memory block with 0 entries, added by local agy hooks, and a list of installed skills that includes this repository's reviewer, paper, pipeline, and research skills. The prompts tell the model to use no tool, file, web search, or skill, and the step rule above stops a run that does. The memory block cannot be removed without changing global agy settings; the plan accepts it for both models because it holds no entry, and for the generator also because generation decides nothing (each pair still passes the mechanical checks and the verifier). Before the first judge call on a claim, the maintainer runs the probe again for each agy model that judges and keeps its output with the raw outputs; a memory block with any entry stops the run. This check is a procedure, not a script step. In version 4 no judge runs through agy, so the probe does not apply; the API judge receives the batch prompt and nothing else. The codex probe reported no added instruction beyond the working directory, shell, date, and permissions.
- Each judge reads each batch twice (two replicates, each a fresh session). A first-attempt prompt is at most 27,500 UTF-8 bytes and a retry at most 28,000, the same batches for both judges.

## Decoys

- False contrast sentences: up to 20 per manuscript (60 in all), each written by the generator from one explicit manuscript statement, changed in one to four tokens so that the manuscript contradicts it. They enter the batches as ordinary items with neutral ids, so the judge cannot tell them from real claims by id or position. A judge must rate at least 0.95 of them `false` in both replicates; a pass shows that the judge, with this prompt and these batches, finds a contradiction that the manuscript states.
- Accurate contrast sentences: the matched accurate twin of each false sentence, in a different batch from its twin. A judge must rate at most 0.05 of them `false` in either replicate; a pass shows that the judge does not call supported text false.
- A pair enters only when it passes the four mechanical checks in `scripts/dispatch_panel_claim_audit.py` (one sentence each, 8 to 50 whitespace-delimited words, one to four changed tokens, a verbatim evidence quote) and the verifier gives one answer for it, with all eight questions in `prompts/contrast_verify.md` true. The script's one-sentence check never rejects a period after a lone letter (an initial, "U.S."); the verifier's eighth question, single_sentences, covers the cases characters cannot settle, such as "group A. The". Two known limits of the script's check, accepted before the freeze: an initial written with a separate combining accent (E followed by U+0301) is still counted as a sentence end, so such a pair is rejected; and a period after a non-letter character such as "½" is not counted as an end, so the verifier's single_sentences answer is the only check there. The build reads the pairs back from the logged generator and verifier outputs and runs the mechanical checks again. Fewer than 15 accepted pairs for a manuscript stops the run.
- Limit: a contrast sentence is one plain sentence, while a real claim is a paragraph, so the decoys test contradiction-finding, not the full reading of a long claim. The verifier is the same model as one judge, so the accepted pairs can favour what that model finds; the second judge is the cross-check.

## Stop rules

- A judge that misses either contrast bar is void; when both judges miss, the measurement is void and no claim rate is published.
- A claim inventory other than 17 bundles and 805 claims, or any extraction problem: stop before any judge call.
- Fewer than 15 or more than 20 accepted contrast pairs for any manuscript, a repeated pair or sentence, or a pair with any check not true: stop before any judge call on claims.
- A batch whose output cannot be read after its one retry: stop the run.
- A transport failure, decided from the CLI's event stream or the API response fields and never from searching its text: a nonzero exit, a failed turn or error event, no completed turn or successful result, a finish reason other than `STOP`, an empty reply, or any step other than the reply (a command, a file read, a tool, a skill, a subagent, a function call): stop the run without a retry. No replacement model or transport without a new plan version.
- An interrupted call, an output that does not match its logged call, a decisions file or seat key from another build, or any input changed since the build: stop.
- A reply that uses a tool, a skill, or a subagent: stop, as a transport failure.
- `budget_exhausted` on the spend ledger: stop. The Gemini pilot has a 5 USD cap. The maintainer sets the full-run cap when approving the projection, at most 100 USD under this plan version.
- The full run starts only after the maintainer approves the pilot projection.

## Amendments

- **Version 2 (2026-10-23), after the v1 pilot and before the full run.** The v1 pilot sent 3 batches to each judge (replicate 1). Both judges rated one false contrast sentence `not_verifiable`: it reverses the manuscript's stated power result ("greater than .80" to "less than .80"), and both cited R4. In v1, R4 said that a claim recomputing a statistic is `false` only when it misstates the manuscript's inputs, and that a disputed arithmetic result with correct inputs is `not_verifiable`; auditor rule 4 kept only the second part. Neither said how to treat a claim that misstates a result the manuscript reports, which this sentence does. Version 2 adds that case: R4 in `rubric.md` and rule 4 in `prompts/auditor.md` now say that a claim stating a reported value or result differently from the manuscript is `false` under V1, and keep both v1 recomputation rules; the other `not_verifiable` cases (V3, auditor rule 6) are unchanged. Bars, arms, decoys, and stop rules are unchanged; the accepted contrast pairs are reused (their prompts did not change). The v1 pilot outputs are kept as a record and are not scored with v2; the v2 build and pilot start in a new directory.
- **Version 3 (2026-10-23), after the v2 pilot and before the full run.** In the v2 pilot, `gemini-3.8-flash-high` answered its first batch as a long list instead of JSON Lines, ran past its output token limit, and agy reported an error; the stop rule ended its run without a retry. `gpt-6-astra` read all three of its batches. Version 3 changes the Google judge to `gemini-4-argon-high` ("Gemini 4 Argon (High)" through agy), the model this plan named before v1; bars, rubric, prompts, decoys, and stop rules are unchanged.
